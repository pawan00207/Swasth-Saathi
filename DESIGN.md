# Design

## Direction

Swasth Saathi reads like an editorial care guide set in an Indian clinic. Warm paper and a documentary-style generated image make the landing page welcoming. Forest teal identifies primary actions. The care directory uses plain labels and aligned rows for scanning.

## Surfaces

The landing page leads with finding care. Its photograph is representative, generated with ImageGen, and depicts no actual patients or providers. Feature screens use the same type and colors with quieter surfaces, clearly marked states, and task-first layouts.

## Typography and interaction

Newsreader is reserved for major headings. Manrope handles navigation, labels and forms, with system fallbacks for other scripts. Keep visible keyboard focus, native scrolling, and reduced-motion support. Put demo and availability labels next to the data they qualify.
